# SK-backtest-preview：历史回测（轻量版）

用GitHub Matches.csv（43MB，10万+场）验证基础信号准确率。

## 可以回测的
- 欧盘赔率最低方向的历史正确率（按联赛分组）
- 深盘/平手盘/浅盘的准确率分布
- 联赛特性验证：如挪超H47%→主胜率确实是47%吗
- F1联赛抽水比的验证：抽水越高是否准确率越低
- 修正14超深盘（客让≥1.25球）的历史打出率

## 不可回测的
- 赔率变动路径（历史数据只有单一时间点）
- 竞彩辅助验证
- 修正1让球变动>5%（需要两个时间点）
- 精算5步

## 输出
- 联赛×盘口深度×方向准确率矩阵
- 高频信号的历史胜率表
- F1抽水比与准确率的相关性验证

## 使用
`/SK-backtest-preview` → 读取Matches.csv → 计算→报告
首次运行约30秒。
