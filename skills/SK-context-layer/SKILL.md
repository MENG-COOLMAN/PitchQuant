# 情境因子层（V3.5.30修正版）——不量化伪装

在1.10基本面后执行。修正规则不变，因子仅降级/标注，不使用假精确系数。

## F1：竞彩/欧盘抽水比（替代主观流动性分级）
竞彩抽水/欧盘抽水 > 1.3 → 竞彩在此联赛严重失真 → 信号降一级
竞彩抽水/欧盘抽水 < 1.0 → 竞彩比欧盘更可信 → 不降
中间 → 不调整
数据来源：每场分析自动计算，基于实际抽水率而非预设值。

## F2：信息真空
赛季前三轮 / 杯赛前三轮 / 转会窗刚关闭 → 标注「信息真空」
→ 所有P0/P1信号降一级
→ 修正21阈值从10%降至8%

依据：信息不对称更大时，赔率的噪音成分上升（通用精算原理，非单场反推）。

## F3：主客反差
主场胜率−客场胜率>30pt → 标注「主场优势极强」
客场0胜 → 标注「客场战力为零」
→ 仅标注，不自动调权

依据：历史数据可客观计算。

## F4：赛程密集度
一周双赛/欧战后联赛 → 标注「体能影响」
→ 仅标注

## F5：德比/死敌
同城德比/保级六分战 → 标注「战意加成」
→ 仅标注

## F6：防守崩坏
客队场均失球>2.0/10场 → 标注「客队防守崩坏」
→ 仅标注

## 核心原则
只降级不升级。仅标注的因子让使用者判断。修正规则本身不改。
