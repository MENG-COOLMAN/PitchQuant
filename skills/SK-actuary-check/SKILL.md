# 精算交叉检查（6步完整版）

## Step1：标记变动幅度级别
<3%：资金管理型（不携带方向信号）
3-8%：混合型（携带弱信号，需Step2-5确认）
>8%：方向信号型（携带强信号，仍需Step2-5确认非风险对冲）

## Step2：跨方向资金流向不对称性
若 A方向降>5% + B/C方向合计升<3% → 资金集中涌入A
→ 市场共识信号。A方向权重保持。
若 A方向降>5% + B/C方向合计升>5% → 对称调整
→ 更可能是方向信号。

## Step3：跨市场验证
竞彩+欧盘在同方向同向变动 → 跨市场共识 → 信号可靠
仅竞彩变动，欧盘不动 → 竞彩资金管理 → 信号不可靠

## Step4：变动连续性
≥3次同向渐进变动 → 持续性方向信号
1-2次突然跳变 → 临时资金管理

## Step5：真实重仓 vs 风险对冲【核心】

| 特征 | 真实重仓（跟） | 风险对冲（不跟） |
|:---|:---|:---|
| 变动节奏 | 多T渐进（≥3次同向） | 短时跳变（1-2次）|
| 跨市场 | 竞彩+欧盘同向 | 单一市场 |
| 让球盘 | 与欧赔同向 | 不动或反向 |
| 水位 | 同步下降 | 不变或上升 |
| 幅度对称 | 升+降幅度接近 | 热门大降，冷门微升 |

判定：≥3项指向真实重仓 → 确认真实重仓 → 信号可靠 → P0/P1正常触发
 ≥3项指向风险对冲 → 标记风险对冲 → 信号降级 → P0→P1, P1→P2

## Step6：精算确认强度与欧盘方向差距联动

欧盘方向差距（公平概率差）与精算确认之间存在叠加效应。差距不足时，精算确认不应自动升级置信度。

| 欧盘差距 | 精算确认真实重仓时 | 精算标记风险对冲时 |
|:---|:---|:---|
| >15pt（明确方向） | 置信度维持，P0正常触发 | 置信度降一级 |
| 10-15pt（倾向方向） | **置信度不升级**，维持原有差距分级 | 置信度降一级 |
| 5-10pt（微弱优势） | 仅标注，不触发P0 | 置信度降一级，倾向取消 |
| <5pt（均衡） | 均衡方向维持，不触发P0 | 不输出方向 |

## 应用
```
长崎客胜：渐进4次+竞彩欧盘同向+让球同向 → 真实重仓 → 信号可靠
山形平赔锁死：5T零变动 → 非真实重仓非对冲 → 双向标注
费耶诺德：欧盘极低+让球同步 → 真实重仓 → 信号可靠
```
