# SL-elo-fetch — 实时 ELO 数据获取（clubelo.com·接入）

> 🔴用途: 模型 ELO 数据空缺补充——修正41 ELO 一致性（原「无数据源标无数据」→现 clubelo 实时源）·R19 实力差距当前赛季 ELO 差交叉验证
> 🔴触发: Step0 数据获取（五大联赛/欧战比赛·预测前·可选但推荐）·调脚本抓取 → 查两队 ELO → 算 ELO 差 → 输出供修正41/R19 消费

## 数据源

```
clubelo.com（ClubElo·免费·每日更新·页面内嵌当前赛季各队ELO+赛前ELO差/Elo胜率）
覆盖: 五大联赛 Level1（德甲18/英超17/西甲20/法甲18/意甲19·2026-27）+ 欧洲各国联赛（含欧战球队）
数据: 每队 ELO 精确值(浮点)+全球排名+联赛级别(Level1=顶级)
```

## 抓取与查询脚本

```
抓取(更新缓存): PYTHONIOENCODING=utf-8 python data/tmp/fetch_clubelo.py
  → 输出 data/tmp/clubelo_<YYYYMMDD>.json（date+五大联赛Level1球队表）
查询(读缓存·按队名): 读最新 clubelo_*.json → 队名模糊匹配 → ELO值 → ELO差
  🔴缓存时效: 每日更新·当天数据可直接用·跨天需重新抓取（免费源·低频防封）
```

## 分档表（🔴clubelo 体系·观察项·随案例库积累校准）

```
🔴注意: clubelo ELO 与 Matches.csv 内置 ELO 是两套体系（量纲不同·阈值不通用）
      R19 历史回测 ELO 差口径(<100接近/>400悬殊) 基于 Matches.csv·不可直接套用 clubelo 值

clubelo ELO 差分档（经验初值·case73-77 校准: 马拉加2/博洛尼亚1=接近·奥萨苏纳29=接近边界·富勒姆69=中等·罗马99=中等偏大）:
  <30    接近（均势·平局权重升·联动修正53/rule64）     → R19: 小球基准(46.3%)·大球小比分候选
  30-100 中等（主队优势·方向按赔率档）                 → R19: 大球中性(47-53%)
  >100   差距大（方向确认·主胜/客胜升权）              → R19: 大球偏多(53-56%)
  >200   悬殊（强队方向锁定·联动R1深盘）               → R19: 大球基准(56%+)/大比分候选
```

## 消费（Step5/6/7）

```
①修正41 ELO 一致性: 方向判定后交叉——ELO差<30 与 平局方向 互证 / ELO差>100 与 主客方向 互证
  冲突 → 标注「ELO 与赔率背离」·以赔率水位+基本面为主（回归V3.5.67）·不单独反方向
②R19 实力差距: 当前赛季 ELO 差 → 分档 → 大球/大比分量化参考（主口径=欧赔隐含差·ELO 仅交叉）
③均势平局: ELO差<50 → 平局率升（意甲31.2%最强·R体系）·联动修正53 S5
```

## 局限与铁律

```
- 第三方免费源·无 SLA·抓取失败/无缓存 → 显式三态标注「ELO 无数据(原因)」·禁止跳过或臆造
- clubelo 英超 Level1 页面 17 队（2026-27 实际状态·以页面为准·升班马可能缺失）
- 数据为赛前 ELO·转会/伤停不直接反映（与赔率互补·不替代赔率主信号）
- 分档为观察项（n=5 校准）·达 71 场窗口批量复核·不固化铁则
- ELO 不参与 prestep 先验筛选（先验=纯赔率10信号·零 ELO）
```
