### 欧战赛事抽水现状（诚实说明）
```
Matches.csv(22.7万场)无欧冠/欧联/欧协联俱乐部赛事——仅EC(欧锦赛国家队)7.29%
历史赛果库有欧战赛果(欧冠920/欧联839/欧协联1480场)但无赔率字段→无法算历史抽水

仅有的观测: 2026-08-13 欧联杯6场实时计算
  竞彩抽水 12.86%-12.99% vs 欧盘 6.87%-7.20%
  竞彩/欧盘比 1.80x-1.88x 🔴

结论(观察项·非铁证): 竞彩对欧战赛事抽水普遍>12.8%
  → 欧战赛事默认触发反抽水(欧盘为准)
  → 待累积更多欧战样本后固化为基准
```

### 欧战抽水样本累积（执行规范·每次分析欧战必做）
```
每分析一场欧战(欧冠/欧联/欧协联)比赛，强制记录到案例库:
  ① 竞彩抽水率（Σ(1/赔率)-1）
  ② 欧盘抽水率（取抽水最低机构）
  ③ 竞彩/欧盘比

累积门槛: 30场欧战样本 → 固化为"欧战抽水基准"(铁证)
当前进度: 6场(2026-08-13欧联杯)，竞彩/欧盘均值1.85x
固化标准: 30场后统计竞彩/欧盘比中位数，若>1.30则确认"欧战默认反抽水"
```
