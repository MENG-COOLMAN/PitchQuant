## 修正50+：庄家盈亏矩阵反推（🔴核心·精确计算·替代频率先验）

> 用户指令：不用"前几场2:2就上调平局/高比分就上调主锚定"的频率先验——
> 用赔率+资金流反推**庄家盈利点在哪、风险暴露在哪个比分**，精确判定主锚定。
> 数据源：①欧盘CS静态赔率(get_odds market=Correct Score·全量比分) ②竞彩比分盘逐T变动(源A·资金流代理) ③跨机构分歧(1xbet vs Bet365)

### 第一步·CS赔率去抽水 → 隐含概率矩阵（🔴必算）

```
取欧盘CS全量比分赔率(120条: 0-0到5-3+):
  overround = Σ_i(1/o_i) - 1     （全量比分总抽水）
  P_i = (1/o_i) / Σ_j(1/o_j)     （每个比分的去抽水隐含概率）
输出: 全量比分概率表 + 按P_i降序排名
```

### 第二步·庄家盈亏定位（三信号交叉·🔴必算）

```
信号1·资金流(竞彩比分盘逐T变动·源A):
  比分i初盘→临场赔率下降>3% → 资金流入 → 庄家风险暴露(怕打出) → 主锚定候选
  比分i赔率上升>3% → 资金流出 → 庄家盈利点(诱盘·鼓励投注) → 显式排除
  降赔最多的3个比分 = 庄家最怕打出 = 主锚定Top候选
信号2·跨机构分歧(1xbet vs Bet365):
  |o_1xbet_i - o_B365_i| / min > 15% → 机构定价不一致 → 标注"争议·谨慎"不主锚定
信号3·方向约束+概率集中度:
  比分必须在方向判定内(1X2∩O/U∩BTTS交叉) 且 P_i靠前 → 主锚定
  方向外但资金流入+P_i高 → 标注"邻方向出口"(修正40跨方向出口37.5%)
```

### 第三步·主锚定判定规则（🔴精确·替代频率先验）

```
第一主锚定 = 方向内 ∩ 资金流入(降赔>3%) ∩ P_i靠前(信号3) 三信号全满足
第二主锚定 = 方向内 ∩ (资金流入或P_i靠前) 二信号
庄家盈利点(升赔>3% 或 方向外) → 显式排除并标注"诱盘"
高比分(3:2/4:2/2:2等)只有在【CS赔率被压低(相对另一机构/相对初盘)+资金流入】时才进主锚定，否则仅标注
  → 直接回应"这几场2:2未来可能1:1"：2:2是否主锚定看它的CS赔率与资金流，不看历史频率
```

### 第四步·输出格式

```
锚定比分: 2:1(P_i=12.3%·降赔5.2%·方向内·庄家暴露) | 3:1(P_i=8.1%·降赔3.5%)
诱盘排除: 2:2(升赔8%·庄家盈利点) | 0:0(方向外)
争议标注: 1:1(跨机构分歧22%·谨慎)
```
