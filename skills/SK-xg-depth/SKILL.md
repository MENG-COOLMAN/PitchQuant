## 流程
### 🔴两阶段彻底分离（2026-08-23审计修复·用户要求"先判7组·再用xG判组内"）
```
阶段1 先判 7 组别: 用【原始xG】(未缩放·与1992场校准口径一致)
   净胜组别 = 亚盘盘口(hdp映射) + xG差升档(0.3/1.0/1.8·78.8%校准)

```

### Step1 数据获取（understat·双轨基线·防泄露）
1. 🔴**双轨基线**（赛前可得·不泄露）:
   - ① 历史完整赛季: `team_avg_xg(league, 2025, n=38)`（上赛季 n=34-38·跨赛季攻防实力·赛季初主力基线）
   - ② 本赛季滚动: `team_avg_xg(league, 2026, n=6)`（赛季初 n<5 标「本赛季无数据」·不臆造）
   - ⚠️升班马/更名无基线 → 标「无数据」·阵容变化大时标注参考性下降
2. 输出: home_xg_avg / away_xg_avg / home_xga_avg / away_xga_avg（双方）

### Step2 特征（滚动统计·区分 2-1/3-2 核心）
- avg_xg / avg_xga（攻防均值·滚动 N 场）
- vol 波动系数（xG 标准差·大开大合→3-2/4-3 倾向）
- 攻防开放度 = (主攻+客防)+(客攻+主防)（总进球量级参考）

### Step3 双泊松分层（净胜与量级解耦）
```
① λ0 = 滚动 xG 均值（主进 (h_xg+a_xga)/2 · 客进 (a_xg+h_xga)/2）
② 亚盘锁净胜: 仅微调差值 ±5%（不破坏基本面·盘口→净胜组别）
   hdp≤-1.75→3+组 · ≤-1.0→2组 · ≤-0.25→1组 · ≥1.75→-3+组 · ≥1.0→-2组 · ≥0.25→-1组 · 其余→平局组
③ 大小球修正量级: 线≤1.85或波动大→总进球上浮(3+球比分升权) · 线≥2.05或防守稳(xGA<1.0)→下浮(≤2球比分升权)
```
