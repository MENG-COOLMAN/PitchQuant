# 修正21-25 通用化版 —— 反向校验模块

由主技能 SK-model-v3-analysis 在第三章比分筛选阶段自动调用。
不独立使用。

---

## 修正21：跨市场分歧

```
竞彩热门赔率 vs 欧盘中位数：
  差异 < 5%  → 正常
  差异 5-10% → 观察
  差异 > 10% → 显著分歧 + 热门方向权-10%
```

## 修正22：高水位观察

```
竞彩水位 > 8% + 锁死 + 降赔 → 信号C从P1降为观察级P1
标注「高水位下机构利润空间充足，降赔动机可能非防御性」
不自动降权，联合修正21触发时叠加
```

## 修正23：共识密度

```
统计6维度中指向同一方向的数量
>=4维度一致 → 输出标注「共识密度高，市场对该方向定价充分」
不单独降权，仅在修正21也触发时联合降权-10%
```

## 修正24：比分3层排序

```
第1层-变动：A降>5% > B降2-5% > C冻结/微动 < D升>5%
第2层-置信：赔率<30的冻结靠前(信号)，>50的冻结靠后(噪音)
第3层-总进球：与峰值一致靠前，偏离>2球靠后
禁止按赔率绝对值排序！
```

## 修正25：方向-比分独立互证

```
比分模块A+B层方向分布 vs 方向模块判定：
  >=60%属于判定方向 → 一致
  <40%属于判定方向 → 冲突
  冲突 + 修正21触发 → 双重预警 + 多方向输出
```

## 修正19（嵌入）

```
让球 != 0 → 铁则34(基差三条件)完全禁用
替代：让球独立变动+半全场+比分盘三重交叉
```
