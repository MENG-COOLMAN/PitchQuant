# 欧国联子模型（SK-league-nations）V3.5.75

> 🔴 **定位**：`Step4.5 联赛/赛事子模型` 的国家队分支。命中 → 输出 R1-R10 → **回归主模型 Step5-8 消费**（不替代主模型判定）。
> 🔴 **铁律**：**只调置信度 · 永不反转 L2 硬核方向 · 最多 ±1 档 · 未回测项仅提示 · 无数据三态标注**。

## 触发条件（N1 赛事识别）

```
league_id == 5 或 league_name 含 "Nations League"/"欧国联"
且 非 Women / U19 / U21 / U23 / U17     → ✅ 激活本子模型
league_name 含 "Friendlies"/"Friendly"  → ⚪ 不确定（走友谊赛口径·非 NL·三态标注）
其余                                    → ❌ 不激活（走原俱乐部流程·零改动）
```
调用：`python data/tmp/nl_model.py --league-id 5 --elo-h <主队Elo> --elo-a <客队Elo> --md <比赛日> --o-h --o-d --o-a [--n-books --spread]`

## 🔴 2026-09-27 加固（case206/207 根因修复·用户确认固化 A+B+C）

> 背景：case207（冰岛 1:1 爱沙尼亚·单押主胜 ✗）与 case206（保加利亚 1:2 卢森堡·漏客胜 ✗）暴露三条缺口。

### A. R10 edge 必须进 Step5（禁只作串关门禁）
- **edge ≤ −10pp**（市场显著高估该方向·如 case207 主 **−17.09pp**）→ 🔴 **该方向不得单押**：置信度**降 1 档** + **强制并列**（并入次优方向 / 平局）
- **edge ≥ +10pp**（市场低估）→ 该方向可**升 0.5 档**；**|edge| < 10pp** → 仅标注·不调整
- ⚠️ 诚实标注：edge 的「分方向用法」**暂无 NL 全样本回测**（NL 无赔率库）→ 仅作**降档/并列提示**·**永不反转 L2 硬核方向**

### B. 超域清单已补两条方向类规则（见上表末两行）
- NL 场**禁用**五大 skew 阈值（强共识 ≥200% 单押 / 弱共识 <150% 只补平局）
- 方向以 **R2 先验（主 43.0 / 平 25.1 / 客 31.9）+ R4 Elo 档位实测 + R10 edge** 为主

### C. 两向覆盖纪律（NL 弱共识场·2026-10-29 修订：三向已废·最多两向）
- skew <150%（弱共识）→ **只写两向：首选 + 平局**（🔴2026-10-29 用户指令废止三向·第三方向只进概率表·禁写入预测方向字段）
- 🔴 仅写「主胜+平局并列」而把第三方向留在概率表 = **未覆盖**（case206 客 26.5% 未被列为方向 → 判 ✗）
- 依据：NL R2 先验客 **31.9%** / 平 **25.1%** 均不可忽略；R4 50-100 档客 26%
- 🔴 口径配套：概率展示 /「覆盖」表述**不构成方向声明**（2026-09-27 用户确认·见案例库模板「命中判定口径」）

### 四、使用要点（执行时必守）
