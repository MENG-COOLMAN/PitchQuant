# 欧国联子模型（SK-league-nations）

> 🔴 **定位**：`Step4.5 联赛/赛事子模型` 的国家队分支。命中 → 输出 R1-R10 → **回归主模型 Step5-8 消费**（不替代主模型判定）。
> 🔴 **铁律**：**只调置信度 · 永不反转 L2 硬核方向 · 最多 ±1 档 · 未回测项仅提示 · 无数据三态标注**。

## 触发条件（N1 赛事识别）

```
league_id == 5 或 league_name 含 "Nations League"/"欧国联"
且 非 Women / U19 / U21 / U23 / U17     → ✅ 激活本子模型
league_name 含 "Friendlies"/"Friendly"  → ⚪ 不确定（走友谊赛口径·非 NL·三态标注）
其余                                    → ❌ 不激活（走原俱乐部流程·零改动）
```
调用：`python data/tmp/nl_model.py --league-id 5 --elo-h <主队Elo> --elo-a <客队Elo> --md <比赛日> --o-h --o-d --o-a [--n-books --spread]`

## 数据基础（658 场·四届全样本）

| 指标 | 值 |
|:--|--:|
| n | **658**（2018/19·2020/21·2022/23·2024/25） |
| 主/平/客 | **43.0% / 25.1% / 31.9%** |
| 场均进球 | **2.51** |
| O2.5 / BTTS | **45.3% / 45.1%** |

🔴 **禁用**：友谊赛（2.88/51%）· 世界杯（2.88/52%）· 欧洲杯（2.78/51%）口径 —— NL 是**独立偏小球赛事**。
⚠️ 样本边界：`tier`/`md` 字段仅 282/658 填充 → 级别梯度分析仅基于 282 场。

## R1-R10 规则集

| 规则 | 内容 | 状态 |
|:--:|:--|:--|
| **R1** | 赛事识别 + 三态标注（见上） | ✅ 直接做 |
| **R2** | 主/平/客先验 **43.0 / 25.1 / 31.9** | ✅ n=658 |
| **R3** | 场均 **2.51** · O2.5 **45.3%** · BTTS **45.1%**（禁跨赛事套用） | ✅ n=658 |
| **R4** | Elo 分档表（9 档·实测）：`<−300` 9/28/63｜`−300~−200` 19/27/55｜`−200~−100` 34/30/37｜`−100~−50` 35/35/31｜`−50~50` **56/24/20**｜`50~100` 56/19/26｜`100~200` 63/21/16｜`200~300` 80/13/7｜`>300` **96/4/0** | ✅ 实测 |
| **R5** | 🔴 **客队热门平局泄漏**：客中浅热门（−200~−50·n=197）→ 实际客胜 **35%** · 平 **31%** · **未胜 65%** → **禁当稳胆·平局按 27-31% 评估·串关降 1 档**；中深（n=86）平 27%·超深（n=67）平 **28%（非零·保留 0:0/1:1 出口）**。该档最常见比分 **1:1 14.2% / 0:0 11.2% / 主队爆冷 1:0 10.7%** | ✅ 实测（本子模型最值钱规则） |
| **R6** | **主客进球不对称**（🔴 用实测值）：主强 >300 → **总 3.76 · O2.5 72% · BTTS 32%**（零封大胜 3:0/4:0）；客强 <−300 → **总 2.27 · O2.5 37%**（窄胜 0:1/0:2）；→ **同档实力下主热门偏大球、客热门偏小球** | ✅ 实测（修正参考材料的拟合值混用） |
| **R7** | **均势场**（−50~50·n=124）→ **中性：总 2.65 · O2.5 45.2%**（🔴 **修正**参考材料"均势小球 40%"的结论） | ✅ 实测 |
| **R8** | **主场参数**：保留主场 Elo 加成 **≈60.7**（国际赛事常规 60-65）·🔴 **不归零/不下调** —— 主胜率 43.0% 偏低源于中档平局多+客热门赢不下来，**非无主场** | ✅ 拟合 |
| **R9** | **战意分级**：MD1-2 **全部 MOT_HIGH**（积分清零·无人出局）→ 🔴 **禁用死球淡化**；MD3-4 按实时积分判 MOT_MIXED；MD5-6 才启用升级/保级/死球。战意只调置信度（≤0.5 档） | ✅ 直接做 |
| **R10** | **公平赔率 edge**：`log λ = base + slope×Elo差`，base=0.800 / slope主=0.00050 / slope客=0.00172 / adv=60.7。**edge = 公平概率 − 市场去水概率**；🔴 **仅 edge>0 且公平置信 ≥0.60 才进串关**（分档实测：**≥0.60 → 78.6%** / 0.50-0.60 → 51.5% / 0.40-0.50 → **36.8%（不进串关）**） | ✅ 时间分割验证（后 20% n=132·方向 53.8% vs 基准 40.9% = **+12.9pp**·单调递增） |

## R10 公平模型的验证证据

| 项 | 结果 |
|:--|:--|
| 训练/验证 | 前 526 场（2018-09-06~2024-09-10）/ 后 **132 场**（2024-10-10~2025-06-08） |
| 验证方向 | **71/132 = 53.8%**（基准 恒押主 **40.9%** → **+12.9pp**） |
| 分档单调性 | 36.8% → 51.5% → **78.6%** ✅ |
| **O2.5** | 🔴 **53.0%（≈基准）→ 未复现参考材料声称的 60.9% → O2.5 不接入公平模型** |
| 参数可辨识性 | base 与 adv 共线 → 采用**固定 adv=60.7** 的可辨识形式 |

## N7 资金盘口径（复用主模型模块）

- 复用 `sharp_baseline.py`（Pinnacle ~2% margin 作方向锚）+ `bookmaker_spread.py`
- ⚠️ **NL 机构池更小（9-13 家）→ spread 阈值须按机构数标准化·待 NL 样本重标** → **当前仅标注 n_books + 分歧·不降档**

## 🔴 规则优先级（与主模型既有规则的冲突处理·补）

| 冲突场景 | 优先级 | 处理 |
|:--|:--|:--|
| R6（主客进球分流）vs **goal_bins 量级** | **量级优先** | 量级以「O25 市场 + goal_bins 校准分布」为主·R6 仅作**锚方向分流参考**·🔴不覆盖量级中心 |
| R10（公平 edge）vs **市场源优先铁律** | **市场优先** | edge 仅作**独立参考**·仅 edge>0 且公平≥0.60 才进串关·🔴不覆盖市场判定 |
| R5（客热门平局）vs **修正53/R20 平局序列** | **叠加** | 修正53 是信号计数（≥2.5 并列）·R5 是**场次级先验**·两者叠加不替代 |
| R8（主场 60.7）vs **HAF 主客场因子** | **HAF 优先** | NL 无 HAF 档案时才用 R8 替代值（60.7） |
| R9（战意）vs **F7 情境因子** | **叠加** | R9 = 赛事级（MD1-2 禁死球）·F7 = 场次级 |
| **所有 NL 规则 vs L2 硬核方向** | 🔴 **L2 优先** | NL 只调置信度（**≤±1 档**）·**永不反转方向** |

## 门禁纪律（不可弱化）

1. 任何调置信度的 NL 新规则 → 先在 NL 库做**时间分割（前 80%/后 20%）**，**显著（p<0.05）且 ≥3pp** 才进判定链；未达标**只标注**。
2. **永不反转 L2 硬核方向 · 最多 ±1 档**。
3. 无数据**三态标注**，禁止幻觉数字；外部数据记录来源与口径。
4. 数据主库 = `data/tmp/nl_data/nl_with_elo.csv`（658 场·md5 323a44dd）；参数 = `fair_model.json`。

## 已知边界（诚实标注）

- 658 场总量薄（单档 25-197 场·主强 >300 仅 n=25）→ 所有数值须标 n
- **api-football 免费套餐无 NL 历史逐家赔率**（results=0）→ 无法做"公平概率 vs 历史市场"的全样本 edge 回测（R10 的 edge 侧仅理论可用）
- 本子模型**不预测晋级/出线**（仅单场分析）
- **不改动任何俱乐部流程**（仅 league_id=5 时激活）
