# SK-prestep-filter 先验筛选（被动·用户指令触发）

## 🔴触发条件
- 用户消息含「先验」（如「先验一下今晚的五大联赛」「筛选信号强的比赛」）→ **执行本 skill**
- 未下达先验指令直接发竞彩txt → **跳过本 skill·按原模型 Step0-11**（被动模块·零干扰原流程）

## 流程

### PreStep1 数据获取（Odds-API）
🔴**时间窗口（固定）**: 指令发出当天 **北京时间22:00 → 次日凌晨06:00**（8小时窗口）= UTC **当天14:00 → 当天22:00**
1. `get_events(sport=football, league={england-premier-league|spain-laliga|germany-bundesliga|italy-serie-a|france-ligue-1}, from=<当天>T14:00:00Z, to=<当天>T22:00:00Z, status=pending)` → 窗口内五大联赛全部赛事（eventId+球队）
2. `get_multi_odds`（≤10 event 一次）或逐场 `get_odds(eventId, bookmakers=1xbet,Bet365)` → 每场 ML/Spread(亚盘水位)/Totals(大小球)
3. 数据缺失/网络故障 → 标注「数据获取失败·稍后重试」·不臆造

### 🔴 PreStep2 双向评级（V2··用户要求"每次 prestep 同时输出方向评分和比分评分"）

**执行方式（脚本化·避免手算）**:
```bash
python data/tmp/prestep_dual.py --match "赛事,主,平,客,让球,O25[,水位差,联赛]"
python data/tmp/prestep_dual.py --file data/tmp/_prestep_input.txt   # 每行一场
```
**输出（每场两套独立评级 + 综合判定）**:
| 输出项 | 含义 |
|:--|:--|
| **方向分** | 原 10 信号（D1/D2/D3/N3/N4/G1/G2/H1/H2/O10/H3）· ≥3 = 推荐（65.5% 命中）|
| **比分分** | V2 比分可预测性（强小球+3·中盘+2.5·深让+2·极端共振-6…）· ≥2.5 = 比分推荐 |
| **比分锚建议** | 按 方向+让球层+O25档 查表（Top2 ~25%·粗粒度参考）|
| **双向评级** | 🔴双推荐 / ✅仅方向推荐 / ⚡比分有谱方向弱 / ⏸️比分不可预测 / ❌双低跳过 |

**四级分档（方案 V2.0 验证后采纳）**:
| 比分分 | 档位 | 实测比分Top2 |
|:--|:--|:--|
| **≥2.5** | 强推荐(比分) | **30.42%（+5.55pp·覆盖33%）** |
| ≥0.5 | 推荐(比分) | — |
| ≥-3 | 观察 | — |
| <-3 | 回避(不可预测) | **19.57%（-5.31pp）** |

**组合评级**: 🔴双推荐（方向≥3+比分≥2.5）/ ⚡比分优先（比分≥2.5·方向<3）/ ✅方向优先（方向≥3·比分<2.5）/ ⏸️回避 / ❌双低跳过。
🔴**方案验证结论**: 用户方案 V2.0 经独立复现——①结论可复现（强推荐 29.48%·+4.60pp）②**方案有符号 bug**（`handi=-hs` 致 S2/S3/S9/S10/S11 让球信号全失效）→ 修正后 **30.53%（+5.65pp）**③本模型比分分**等效且覆盖率 2.8×**（802 场 vs 285 场）→ 保留本模型分值。**方向代价**: 比分推荐组方向 38-39%（基准 51%）——侧重比分的必然取舍。
⚠️ 锚建议为**粗粒度参考**（实测该档 Top2 约 25%）·精细锚仍需 Step7 完整流程（查表+泊松+资金流）。

### 🔴 PreStep2-b 比分命中评分（V2··用户要求"侧重比分命中兼顾方向"）

**回测依据**（`data/tmp/prestep_score_backtest.py`·12000 场时间分割·见 `data/online_learning/docs/PreStep比分导向回测_20260911.txt`）：
全局基准 比分Top2 **25.19%** / 方向 50.30%。**关键发现：方向强度与比分可预测性负相关**（主赔<1.30 方向 82.45% 但比分 -1.17pp）。

| 比分可预测性信号 | 实测比分Top2增量 | **比分分** |
|:--|:--|:--|
| **O25>2.10（强小球）** | **+1.45pp** | **+3** |
| **主赔 1.80-2.20（中盘）** | **+1.16pp** | **+2.5** |
| **让≥1.5（深让·排除搭配极端大球）** | +0.70~1.28pp | **+2** |
| 主赔 1.50-1.80 | +0.46pp | **+1** |
| O25 1.65-1.90（中性） | -1.03pp | **-2** |
| O25<1.65（大球侧） | -2.3~3.6pp | **-4** |
| **O25<1.5 + 让≥1.5（极端共振）** | **-5.35pp** | 🔴**-6（不推荐）** |
| **贴水浅让（主<1.5+让<1）** | **-5.06pp** | 🔴**-6（不推荐）** |
| O25<1.7 + 隐含差>25pp | -1.82pp | **-3** |

**综合评分 = 比分分(主) + 方向分×0.5(辅)**（方向分沿用原 10 信号）

🔴**锚可信度分级铁律（案例库 157 场锚命中回测固化）**: 比分锚(主锚/次锚)的可信度由【预期总进球量级×净胜档】决定，必须显式声明——实测(真实赛果分档·锚命中率): 实际总进球 ≤3球 **36.4%**(n=88) vs ≥4球 **2.9%**(n=69)·5+球 **0%**(n=38)；净胜≤1球占命中场 76%·净胜≥3仅 **5.4%**；交叉「≤3球且净胜≤1」**40.0%**(n=65) vs「≥4球且净胜≥2」**4.9%**；命中比分 88% 落在 {1:1,2:1,1:0,0:1,2:0}。→ **①大球场(预期≥3.4球/O25<1.50) 或 深盘大胜(净胜档≥3) → 锚不可信 → 禁把"主锚/次锚"当高置信输出·改输出「宽候选池+比分不可预测」标注(方向仍可用) ②低分小净胜场 → 锚可信(40%)·精细锚定 ③🔴HIGH 置信度 ≠ 比分可信**(实测 HIGH 场锚命中 15.4% 最低档·因 HIGH 多为深盘悬殊场)。**脚本**: prestep_dual.anchor_trust 每场判级(✅可信/⚠️弱/🔴不可信)·output_checker **N08** 块·check_sync 防回退。
**推荐线**: 比分分 **≥2.5** → 比分推荐场（输出主锚/次锚+该档比分命中率）· 比分分 **≤-3** → 标注"比分不可预测·仅方向参考"

**📌 输出要求（每场·🔴方向与比分独立打分·不合并总分）**: ①**方向分**（独立·10信号·≥3推荐）②**比分分**（独立·可预测性·四级档位：≥2.5强推荐/≥0.5推荐/≥-3观察/<-3回避）③**主锚/次锚**（按 方向+让球层+O25档 查表·实测 Top2 30.42%）④该档历史比分命中率 ⑤**组合标签**（🔴双推荐/⚡比分优先/✅方向优先/⏸️回避/❌双低·非数值相加）

⚠️ 诚实边界: 赔率类信号对比分的增益上限约 **+1.5pp**（单信号）·真正提升比分需 **球队攻防/场均进失/xG**（data_bridge 已接入）·后续用 prediction_log 积累样本复核。

## PreStep2 信号打分（10 信号·回测校准·Matches.csv 43,254 场）
```
方向信号:
  D1 深盘主胜(主赔<1.5·实测75.4%·+29.2pp) = +2
  🔴O10浅让降权(2026-09-05): D1/N3触发时亚盘主让<1(浅让0.5-0.75)→-1(诱主·低赔浅让实主56.4% vs 深让74.5%·差18pp·降权不反向)
  D2 深盘客胜(亚盘客让0.75+·实测64.4%·+35.9pp) = +2
  D3 均势必平(主客隐含差5-10pp+联赛平率≥27%(意甲/法甲)·实测30.6%·+5.3pp) = +1.5
  N3 中深盘主胜(主赔1.5-1.8+客赔>4.5·实测59.3%·+13.6pp·与D1零重叠) = +1.5
  N4 客队热门(客赔<2.2+主赔>3.0·实测58.0%·+29.5pp·与D2互补) = +1.5
  🔴N4防平注(2026-09-05): 客让<0.75→附加「防平参考」(O2/case123·不扣分仅标注)
进球信号:
  G1 大球确认(O25<1.7·实测62.9%·+12.9pp) = +1.5
  G2 小球确认(O25>2.1·实测60.1%·+10.1pp) = +1
盘口信号:
  H1 水位背离(主客水位差>0.2·V6修正55: 主高水+大低水58.3%/主高水+小低水58.0%) = +1
  H2 穿盘区间(主让1.25-1.75·实测73.3%·+27.1pp) = +1.5
  H3 反直觉降权(西甲1.5-1.8档/法甲深盘·实测主胜仍58.5%/72.7%·仅主胜降权-1·绝不反向加客胜) = -1
🔴已删除: D4平手主胜(42.4%<基准46.2%·无效·平手≠主胜)
```
预测方向 = 分数最高的方向类信号（主胜/客胜/平局）·**方向分** = 方向信号+进球信号+盘口信号之和（🔴此为方向分内部构成·与比分分**独立**·两者不合并）

### PreStep3 筛选输出
```
🔴阈值（10信号版回测）: ≥4=强推荐(69.5%命中·14.1%覆盖·优先分析) · ≥3=信号强(65.5%·27.0%覆盖·推荐完整分析·HIGH方向) · <3=不推荐(仅用户指定时分析)
输出格式（按分数降序·数量不限）:
  赛事 | 分数 | 触发信号 | 方向倾向 | 置信度层 | 建议
  ─────────────────────────────────────────────
  X vs Y | 4.5 | D1+N3+G1+H2 | 主胜 | HIGH | 强推荐·建议完整分析
  ...
```
输出后 **等用户决定对哪些场做完整分析**（用户发 txt 或点名）→ 转原模型 Step0-11
