## 水位定义

🔴水位两义（数学层面·勿混用）:
- **全盘水位** = 全盘抽水率 = Σ(1/各选项赔率) − 1（🔴**2026-09-21 起不参与方向判定**·仅保留跨市场比较与极端值警戒）
- **亚盘水位** = 让球盘上盘/下盘两边赔率（信号 A/B/E 用·**独立于 1X2 的维度**）
- 两者是不同量: 全盘水位与 1X2 赔率数学耦合（热门赔率↓必推高抽水率）；**亚盘水位才是独立的让球盘方向信号**

## 子信号

### 信号A：水位升降趋势（🔴2026-09-21 限定为**亚盘水位**）
- 🔴 **仅适用亚盘水位**（让球盘上/下盘赔率的时序变动）——全盘水位受 vig 恒等式污染，**不参与方向判定**
- 亚盘水位降低 > 1%：机构压缩上盘利润 → 对上盘方向有预判（🔴须以**盘口未变**为前提）
- 亚盘水位升高 > 1%：机构扩利 → 上盘方向不确定性高
- 锁死（变动 < 0.3%）：机构不愿调整 → 预判明确

### 信号B：水位方向偏移（🔴2026-09-21 限定为**亚盘水位**）
基于**亚盘让球盘**上/下盘赔率推得的隐含概率时序偏移（单位: pt）：
- 单一方向扩权 > 0.5pt → 机构倾向该方向
- 单一方向萎缩 > 0.5pt → 机构撤离该方向
🔴 全盘水位口径的"隐含概率偏移"**不再使用**（与 1X2 赔率变动同源 = 重复计数）。

### 信号C：亚盘水位 × 让球盘口联动（🔴2026-09-21 降级·全盘水位分量废除）
> ⚠️数学前提: 全盘水位(抽水率)=Σ(1/赔率)−1 是赔率的函数，与热门赔率**耦合**（热门赔率↓必推高抽水率）。
> 🔴**2026-09-21 实测结论（Matches.csv 227,510 场·时间分割 80/20）**:
> 全盘抽水率分档命中率 **47.94% / 52.58% / 49.86% / 49.90% / 49.85%**（vig 0-4% / 4-6% / 6-8% / 8-10% / 10-15%）
> → **无单调关系·全盘水位不携带方向信息**；原「水位↓+热门赔率↓=P0 真实防御」属**同一事件重复计数（数学恒等）**
> → 🔴 **禁止作为方向双确认**。方向判定只看 1X2 赔率变动 + **亚盘水位（独立维度）**。

| 亚盘水位（独立维度） | 让球盘口 | 庄家意图 | 信号 |
|:---|:---|:---|:---|
| ↓降低（上盘贴水） | 加深 | 真实防御，机构贴利压赔 | **P0** |
| ↓降低 | 不变 | 温和防御 | P1 |
| ↑升高（上盘升水） | 不变/退盘 | 诱上盘收割下盘 | **P1 警报** |
| ↑升高 | 加深 | 盘口与水位背离 | 仅标注·以盘口为准 |
| 锁死 | 锁死 | 赛果已定 | P0 |

🔴**P0 真实防御新定义（须同时满足）**:
 ① **亚盘水位独立降低**（非 1X2 派生）② **让球盘口加深** ③ **跨机构 spread 收敛**（`bookmaker_spread.py` 判 CONSENSUS <2%）
 → 三者同时满足才是 P0；缺任一 → 降为 P1 或仅标注。
🔴**跨市场 vig 比较（SL-jc-reverse）不受本降级影响**——那是竞彩 vs 欧盘的**跨市场**抽水比（实测 1.86x 触发），
 与"单市场 vig 高低"机制不同，**继续保留**。

### 信号D：跨市场抽水比（🔴2026-09-21 重命名·原"跨机构水位分歧"）
- 竞彩抽水 / 欧盘抽水 > 1.5 → 以欧盘为准，竞彩降权 ×0.7（衔接 `SL-jc-reverse`）
- 两市场接近 → 互印证
- 🔴 本信号性质 = **跨市场口径校准**，**不是方向信号**（避免与全盘 vig 的方向误解混淆）

### 信号E：亚盘水位动态（🔴欧盘·**本技能最有效信号**）
```
数据源: get_odds Spread（盘口+水位·updatedAt 时间戳）+ zgzcw ypdb 初即盘口水位对比
        （get_odds_movements 免费 tier 404 不可用）
返回: 上盘/下盘水位逐点变动（带时间戳），如 hdp=-0.5 上盘1.9→2.025→1.975

解读（庄家防御 vs 收割·🔴前提: 盘口 marketLine 不变）:
  🔴先确认盘口未变: 若 hdp 从 -0.5 变 -0.75(让球加深)，水位变化是盘口调整的结果，不可用下列"升水/降水"解读
  盘口不变时:
    上盘升水(>0.05) → 机构提高上盘赔率=看衰上盘 → 诱上盘收割下盘 → 上盘方向危险
    上盘降水 + 下盘升水 → 机构真实看好上盘（贴利防御）
    上下盘水位同时微调(<0.03) → 盘口稳定，机构预判明确
  盘口变动(marketLine) → 机构调整让球深度，方向信号强（优先于水位解读）

🔴跨源交叉（2026-09-21 强化·P0 三条件）:
  亚盘水位独立降低 + 让球盘口加深 + 跨机构 spread 收敛(<2%) → **P0 真实防御（三条件齐备）**
  亚盘水位降低 vs 1X2 热门赔率升高 → 可能诱盘（以亚盘为准）
  欧盘上盘升水 vs 竞彩让球盘变动 同向 → 双确认；反向 → 以欧盘为准·标「竞彩诱盘嫌疑」
```
