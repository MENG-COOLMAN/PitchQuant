# 修正20：水位意图分析 —— V3.5.24+++ 增量模块

## 触发
所有比赛自动适用，无特殊触发条件。

## 水位定义

🔴水位两义（数学层面·勿混用）:
- **全盘水位** = 全盘抽水率 = Σ(1/各选项赔率) − 1（信号A/C/D用·是赔率的函数，随1X2赔率联动）
- **亚盘水位** = 让球盘上盘/下盘两边赔率（信号E用·独立于1X2的维度）
- 两者是不同量: 全盘水位与1X2赔率数学耦合（热门赔率↓必推高抽水率）；亚盘水位才是独立的让球盘方向信号

🔴双源水位（哪个真实用哪个）：
- 源A 竞彩全盘水位（用户提供·抽水12.8%偏高）
- 源B 欧盘亚盘水位（Odds-API get_odds_movements market=Spread&marketLine=盘口 → 上盘/下盘逐点变动，抽水6.9%真实）⚠️免费tier 404不可用·改用 get_odds Spread 盘口+水位 + zgzcw ypdb 初即盘口水位对比
- 冲突以源B欧盘为准；竞彩水位>12%时以欧盘水位替代（铁则39）

| 水位区间 | 机构意图 | 信号强度 |
|:---|:---|:---|
| < 3% | 极低利润，机构信心极强，赔率高度可靠 | P1 |
| 3%~5% | 正常区间，赔率可信 | — |
| 5%~8% | 偏高，机构偏保守 | 注意 |
| 8%~12% | 高利润，机构极度保守，参考价值下降 | P1 警报 |
| > 12% | 垄断市场（竞彩），需欧盘交叉校准 | P0 警报 |

## 四个子信号

### 信号A：水位升降趋势
- 降低 > 1%：机构压缩利润 → 对赛果有预判
- 升高 > 1%：机构扩利 → 赛果不确定性高
- 锁死(变动<0.3%)：机构不愿调整 → 预判明确

### 信号B：水位方向偏移
计算各方向隐含概率的时序偏移(单位:百分点pt)：
- 单一方向扩权 > 0.5pt → 机构倾向该方向
- 单一方向萎缩 > 0.5pt → 机构撤离该方向

### 信号C：水位+赔率联动（核心）
> ⚠️数学前提: 全盘水位(抽水率)=Σ(1/赔率)−1 是赔率的函数，与热门赔率**耦合**（热门赔率↓必推高抽水率）。
> 因此"水位↓+热门赔率↓"不是两个独立信号，而是"热门赔率降 + 平/客赔率升"的组合表现。
> 真正独立的联动是: 全盘水位 × 亚盘水位(让球盘) —— 两者才互不耦合。

| 水位 | 热门赔率 | 庄家意图 | 信号 |
|:---|:---|:---|:---|
| ↓降低 | ↓降低 | 真实防御，机构贴利压赔 | **P0** |
| ↓降低 | ↑升高 | 隐形诱盘 | P1 |
| ↑升高 | ↓降低 | 收割信号!左手压赔右手收利 | **P0 警报** |
| ↑升高 | ↑升高 | 方向抛弃 | **P0** |
| 锁死 | ↓降低 | 机构预判，只降赔不调水位 | P1 |
| 锁死 | 锁死 | 赛果已定 | P0 |

### 信号D：跨机构水位分歧
- 竞彩水位 > 欧盘×1.5：以欧盘为准，竞彩降权×0.7
- 竞彩≈欧盘：互印证，信号升级
- 偏移方向一致：双确认

### 信号E：亚盘水位动态（🔴欧盘·新增双源核心）
```
数据源: mcp__odds-api__get_odds_movements (market=Spread&marketLine=盘口) ⚠️免费tier 404不可用·替代=get_odds Spread(盘口+水位·updatedAt时间戳)+zgzcw ypdb
返回: 上盘/下盘水位逐点变动（带时间戳），如 hdp=-0.5 上盘1.9→2.025→1.975

解读（庄家防御 vs 收割·🔴前提: 盘口marketLine不变）:
  🔴先确认盘口未变: 若 hdp 从 -0.5 变 -0.75(让球加深)，水位变化是盘口调整的结果，不可用下列"升水/降水"解读
  盘口不变时:
    上盘升水(>0.05) → 机构提高上盘赔率=看衰上盘 → 诱上盘收割下盘 → 上盘方向危险
    上盘降水 + 下盘升水 → 机构真实看好上盘（贴利防御）
    上下盘水位同时微调(<0.03) → 盘口稳定，机构预判明确
  盘口变动(marketLine) → 机构调整让球深度，方向信号强（优先于水位解读）

跨源验证:
  欧盘上盘升水 vs 竞彩让球盘变动 同向 → 双确认
  反向 → 以欧盘为准，标「竞彩诱盘嫌疑」
```

## 铁则39
水位变动+赔率变动的联动是区分真实防御与诱盘收割的关键交叉验证。水位降低+热门赔率降低=真实防御双确认P0。水位升高+热门赔率降低=诱盘收割警报P0。竞彩水位>12%时以欧盘水位替代，竞彩降权×0.7。

## 口诀27
水位不是常数升降暗藏意。缩水利赔双确认是真防御不用疑。扩水利赔是收割左手压赔右手吸。竞彩水位虽偏高垄断也怕才真急。锁死不调皆有数机构预判莫轻弃。
