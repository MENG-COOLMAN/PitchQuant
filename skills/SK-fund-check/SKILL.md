# 修正26：基本面交叉验证强制步骤

触发条件（普适，任一满足即触发）：
A：主队近10场胜率≥70%且赔率方向≠主胜
B：主队近10场0败且赔率方向=客胜
C：客队近10场胜率≤30%且赔率方向=客胜
D：主主场胜率−客客场胜率≥30pt且赔率方向≠优势方
E（新增）：关键位置伤停——热门方门将缺阵/头号射手缺阵/中场核心≥2人同时缺阵
  →仅当伤停方是赔率热门方向时触发；冷门方不触发（冷门已定价风险）

执行：
触发→「基本面冲突警报」→置信度降一级→冲突出口权+10%
（ABCD→平局+10%；E→非伤停方不败方向+10%）

关联：修正26+修正21同时触发→「双重基本面+定价背离」→双方锚定
条件E可与ABCD任一同时触发→叠加标注

逻辑：机构也会出错。10场不败的球队被定冷门，或胜率不足30%被定热门，
赔率可能不是更聪明而是更有动机。铁则5必须有强制执行步骤。

通用性：PAOK触发? 一致→不触发。Jagiellonia触发? 冲突→触发。
