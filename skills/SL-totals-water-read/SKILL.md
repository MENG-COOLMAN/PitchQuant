## 二、核心原理

### 2.1 盘口线 = 机构期望总进球中位数
机构开线时选 L 使 P(Over L) ≈ P(Under L) → **线 L 即中位数**。每升 0.25 档，机构期望总进球 +0.25。
本模块用 **1xbet Totals 多档（0.5~7.5）插值求「均衡线」**（`fair_line()`）——无需新数据源即可实现 Layer1。

### 2.2 Quarter line 含义
2.25 = 半注 Over2.0 + 半注 Over2.5 → 真实 λ 在 2.0-2.5 之间；2.75 同理 → quarter line 比 half line 更精确。

### 2.3 水位去水（静态）
```
p_over_fair = (1/over) / (1/over + 1/under)
λ_water = line + (p_over_fair − 0.50) × 1.5      # 方案 §3.2
λ_poisson = 泊松反解: 1 − e^(−λ)(1+λ+λ²/2) = p_over_fair
```

