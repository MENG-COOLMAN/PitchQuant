# 示例：意甲某轮 Monza vs Sassuolo（完整流程复盘）

> 本示例来自真实案例库（已脱敏：去除个人记录，保留比赛信息与全部数值）。
> **是"误判案例"**——故意选它，因为它比成功案例更能说明这套流程的价值：**错在哪、机制如何补救、教训如何固化**。

---

## 一、输入（竞彩赔率摘要）

```
【胜平负】 2.67, 3.22, 2.25 → 2.75, 3.22, 2.20 → 2.67, 3.22, 2.25   （三向零变动 · 无资金流信号）
【让球+1】 1.47, 3.95, 5.10 → 1.50, 3.90, 4.85 → 1.48, 3.95, 5.00
【总进球】 末盘: 15.00, 5.90, 3.30, 3.40, 5.45, 9.50, 20.00, 31.00  （2球 3.30 最低）
【比分】   1:1=6.25（全盘最低）· 1:2=8.00 · 2:1=9.00 · 0:1=9.50
```

## 二、欧盘（1xbet 全市场快照）

| 市场 | 数值 |
|:--|:--|
| ML（去水 1.5%） | 主 **34.7** / 平 **28.8** / 客 **36.4** |
| Spread | 均衡线 主受让 0.25（1.65/2.19） |
| Totals | O2.5 1.827 / U 2.137（over **51.0%**） |
| BTTS | yes 1.57（**59.2%**·偏 Yes） |
| CS | **1-2=8.5 最低** · 2-1=9 · 1-0=10 |

## 三、关键判定链（Step1 → Step7）

| 层 | 结果 | 数值 |
|:--|:--|:--|
| 硬核 | 去水 12.95% → 主 33.2 / 平 27.5 / 客 39.3 | 方向差距 **6.2pt**（微弱区） |
| 硬核 | **skew 119%** | → 🔴 **触发「弱共识场平局并列铁律」** |
| 硬核 | 凯利 0.885 · 反抽水 1.88x（>1.30 触发 F1） | — |
| Step4.6 HAF | Monza 主场胜率仅 **24.6%**（主场增益 **-16.4pp**） | 无主场优势 |
| Step5 方向 | 市场首选客胜，但 skew<150% → **客胜 + 平局并列** | 置信度降 1 档 → **LOW** |
| Step5 平局 | R20 双信号激活：S10（受让浅盘→平局率 29.1%）+ S11b（客胜档→28.3%） | 交叉验证平局 |
| Step6 大小球 | 🟡 中信号大球：goal_odds **mean 2.86** / over2.5 **55.2%** | 中心 2.5 球 |
| Step7 锚定 | 主锚 **1:1**（竞彩 CS 6.25 全盘最低 + 查表 D0 46.6%）| 次锚 **1:2**（查表 A1 41.6%） |

**一致性校验**（脚本强制）：
- 锚-市场：净胜期望档 **D0（-0.04 球）** → 主锚 1:1 ✅ 一致
- 锚-量级：量级 2.84 球（中性偏大）→ 主锚 2 球 + 次锚 3 球 → 至少一个 ≥3 球 ✅
- 锚可信度：预期总进球 ≤2.9 球 → ✅ 可信（命中区间 26–50%）

## 四、两次修正（关键：**叠加信息，不摇摆方向**）

**第一次修正**（补 api-football 后）：
- 官方预测「Win or draw」（偏主）+ **客队伤停 7 人（影响分 9.9·极端）** + 交锋近 5 场主队 3 胜 2 平 0 负
- → 三重独立信号指向主队 → 方向一度修正为 **主胜 + 平局并列**

**第二次修正**（补 ELO 后）：
- ClubElo 差 **-67**（利客）→ 独立信号增加，与"利主"信号对冲
- → 按全量数据**诚实回归三向均衡**：**客胜（聚合首选 38.0%）+ 平局并列 + 主胜并列参考**

> 💡 **教学点**：修正 ≠ 摇摆。每次修正都是"**补足缺失信息**"；并且**已确认的方向不删除，只能增加并列**（这条纪律来自更早批次的教训固化）。

## 五、复盘（真实赛果 2:1）

| 口径 | 结果 |
|:--|:--|
| 方向（strict·仅主方向） | ❌（主方向判客胜，真实主胜） |
| 方向（any·含并列参考） | ✅（主胜以"并列参考"形式写出） |
| 比分（主锚/次锚命中） | ❌（真实 2:1，第三锚命中不计） |

**教训与机制**：
1. **弱共识场必须三向覆盖**——本例把主胜作为"并列参考"写出 → any 口径命中；同批另一场（漏写主胜）直接全错。
2. **三向均衡不是缺点**——市场分裂（skew 119%）时，写出全部三种可能并标 LOW，比"自信单押"更诚实。
3. **锚定受量级约束**——本例量级中性偏大，主锚 1:1 + 次锚 1:2 的组合至少含一个 ≥3 球比分，符合"锚-量级一致性"。

## 六、本例演示了什么

- ✅ 多源数据接入（竞彩 / 欧盘 / 官方概率 / 伤停 / ELO / HAF）
- ✅ 脚本化确定性计算（去水 / skew / 泊松 / 查表 / 一致性检查）
- ✅ 规则触发与三态标注（触发就写数值，不触发写原因）
- ✅ 两次修正的"补信息"逻辑（不反转已确认方向）
- ✅ 诚实复盘（方向 strict ✗，不粉饰）
