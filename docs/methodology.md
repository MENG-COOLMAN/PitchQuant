# 方法论与关键回测结论
## Methodology & Backtest Findings

> 本文件记录 PitchQuant 的**统计方法论**与**关键回测结论**。
> 核心原则：**先复现，再固化** —— 任何新规则必须通过时间分割回测（time-split backtest）且统计显著（p<0.05），否则只作"观察项"记录。
>
> *This document records the statistical methodology and key backtest findings. Principle: reproduce first, fixate later.*

## 0. 方法论总则 · Guiding Principles

| 原则 | 含义 |
|:--|:--|
| **先复现再固化** | 任何规则先独立回测复现，再写入模型 |
| **时间分割验证** | 训练/测试按时间切分（70/30），**禁止未来数据泄露（look-ahead bias）** |
| **显著性门槛** | 增益必须通过配对显著性检验（p<0.05），否则不进判定 |
| **样本量门槛** | n<50 → 权重 0；50–200 → 0.05；≥200 → 0.10（封顶） |
| **诚实标注** | 未达门槛的结论标"观察项"；被证伪的方案写入「已否决清单」 |

## 1. 数学基础 · Mathematical Foundation

### 1.1 去水（De-vigging）

博彩赔率内含"抽水"（vig / overround）。三项隐含概率之和 > 1：

```
隐含概率:   p_i = 1 / odds_i
抽水率:     vig = Σ p_i − 1
等比例去水: p_i* = p_i / Σ p_i
```

**但等比例去水有系统性偏差**：实测表明**深盘热门被系统性低估** → 本项目在等比例去水后**追加校准**（基于 22.7 万场实测的分档修正表），校准后的概率才用于凯利与 λ 反推。

### 1.2 泊松模型 + Dixon-Coles 修正

比分建模采用**双变量独立泊松**：

```
P(X=i, Y=j) = Poisson(i; λh) · Poisson(j; λa)
            = (λh^i · e^(−λh) / i!) · (λa^j · e^(−λa) / j!)
```

λh/λa（主/客期望进球）由**欧赔 1X2 概率 + 大小球盘**联合反推（迭代求解至收敛；本项目收敛判据：多初始值偏差 <0.15）。

**Dixon-Coles 低比分修正**（低比分存在相关性，独立泊松会低估 0:0/1:0/0:1/1:1）：

```
τ(x,y) = 1 − λh·λa·ρ     当 x=0, y=0
       = 1 + λh·ρ        当 x=0, y=1
       = 1 + λa·ρ        当 x=1, y=0
       = 1 − ρ           当 x=1, y=1
       = 1                其他
```

本项目取 **ρ = −0.12**（文献标定值），实测使 0:0 与 1:1 的预测概率各提升约 **+1.5pp**。

### 1.3 凯利公式（Kelly Criterion）

```
f* = (b·p − q) / b        其中 q = 1 − p
```

p = 模型概率，b = 净赔率。**注意**：本项目仅用凯利作**相对排序信号**——模型概率本身含不确定性，绝对凯利值不可直接用于资金管理。

### 1.4 亚盘（Asian Handicap）与净胜档

亚盘让球把"胜平负"细化为"净胜球档位"（净胜 0/1/2/3+）。实测：**亚盘定价效率极高**（与真实净胜期望偏差 <0.04 球）→ 亚盘盘口是**净胜档的可靠先验**，本项目据此生成"跨档候选池"（margin candidates），而非单档下注。

## 2. 市场校准度（22.7 万场）· Market Calibration

**问题**：市场概率可以直接用吗？

| 市场最高隐含概率档 | 实际命中率 | 偏差 |
|:--|:--|:--|
| 35–45% | 40.5% | +0.3pp |
| 45–55% | 50.7% | +1.1pp |
| 55–70% | 63.0% | +2.0pp |
| 70%+ | 80.6% | **+4.4pp（系统性热门低估）** |

**结论**：市场（欧赔去水 + 校准）是**校准最好的信号**（±5pp 内），且在热门区间**系统性低估** → 在实时融合引擎中设为**最大单源（权重 0.30）**。

**权重寻优回测（20,000 场）**：

| 配置 | Top-1 命中 |
|:--|:--|
| 纯市场 | 14.07% |
| **市场 0.7 + 泊松 0.15 + 约束源 0.15** | **14.37%（最优）** |
| 旧版（无市场源，泊松 0.20） | 12.32% |

→ **含市场源比旧版 +0.54~2.05pp**。「约束源」（亚盘/大小球的高斯近似）是**噪声源**，权重必须压到 0.06 量级。

## 3. 弱共识分档（skew）· Weak-Consensus Breakpoints

**定义**：`skew = 市场最高隐含概率 / 次高隐含概率`。

| skew | 市场首选命中率 | 处理规则 |
|:--|:--|:--|
| <110% | **36.4%** | 🔴 平局必须并列（≈随机） |
| 110–130% | 38.6% | 🔴 平局必须并列 |
| 130–150% | 43.0% | 🔴 平局必须并列 |
| 150–200% | 48.8% | 可单押（谨慎） |
| ≥200% | **64.6%** | 可单押 |

**结论**：skew <150% 时单押市场首选 ≈ 赌博；**平局并列**可显著提升覆盖（实测八场复盘：若并列可命中 3/8 而非 1/8）。

## 4. 比分锚可信度（157 场案例库）· Anchor Trustworthiness

| 场景 | 锚命中率 |
|:--|:--|
| 实际总进球 ≤3 球 | **36.4%** |
| 实际总进球 ≥4 球 | **2.9%** |
| 实际总进球 ≥5 球 | **0%** |
| 「≤3球 且 净胜≤1」 | **40.0%** |
| 「≥4球 且 净胜≥2」 | 4.9% |

**结论**：**大球场（预期 ≥3.4 球）或深盘大胜场 → 禁止把"主锚/次锚"当高置信输出**，改输出宽候选池 + "比分不可预测"标注（方向仍可用）。命中比分 **88%** 落在 `{1:1, 2:1, 1:0, 0:1, 2:0}` 五个比分内。

## 5. 大小球信号分层（148,397 场·时间分割）· Over/Under Signal Tiers

| 档 | 阈值（over 概率） | 实测下限 |
|:--|:--|:--|
| 🔴 强 | ≥58% / ≤42% | 大球 **65.0%** / 小球 **62.6%** |
| 🟡 中 | 55–58% / 42–45% | 57.0% / 58.0% |
| ⚪ 弱 | 53–55% / 45–47% | 54.8% / 54.1%（≈随机·仅参考） |
| ⚫ 中性 | 47–53% | 不判方向 |

**基线**（53% 阈值全档）：**59.54%**。
**极端档提示**：隐含大球 ≥65% 时实际仅 70.9–71.4%（65–75% 区间系统性高估 5–6pp）→ **禁按隐含值线性外推大胜比分**。

## 6. 防过拟合门禁（四道）· Anti-Overfitting Gates

| 门 | 规则 |
|:--|:--|
| ① 回测门 | 时间分割回测 + 配对显著性 **p<0.05** |
| ② 样本门 | n<50 → 权重 0；50–200 → 0.05；≥200 → 0.10 |
| ③ 回滚门 | 滚动 20 场偏差 >10pp → **自动降级为"仅记录"** |
| ④ 裁剪门 | 超范围值丢弃 / 缺失不计入 / 无数据三态标注 |

**真实案例（自我否决）**：在线机器学习层（online learning, river）经 **30,000 场时间分割**实测**无增益**（方向 34.5% vs 热门基准 48.7%，**−14.2pp**）→ 本项目将其**显式降级**（`status: degraded`，权重 0），仅保留记录功能。

> 一个能**证伪自己组件**的系统，比一个只会宣传成功的系统更值得信任。

## 7. 置信度口径 · Confidence Calibration

| 档 | 定义（strict 口径·仅主方向） | 典型场景 |
|:--|:--|:--|
| HIGH | ≥70% | 深盘悬殊场（注意：此时比分锚反而不可信） |
| MID | 55–70% | — |
| MID-LOW | 45–55% | — |
| LOW | <45% | 弱共识场（含并列） |

**口径纪律**：统计一律用 **strict**（仅主方向命中）；含并列/次方向的宽口径（any）会虚高，仅作参考。**基准对照**：热门基准（始终选最低赔率方向）/ 随机 33.3%。

## 8. 已否决清单 · Rejected Approaches（同样重要的诚实）

| 方案 | 回测结论 | 处置 |
|:--|:--|:--|
| Shin 去水法（z 值法） | z=1.0 异常 | ❌ 废弃（改回校准表） |
