# 方法论与关键回测结论（Methodology）

> 所有数字来自本项目的回测（主要数据源：22.7 万场历史比赛 / 时间分割验证）。**先复现、再固化**——任何新规则必须通过时间分割回测且统计显著，否则只作"观察项"记录。

---

## 1. 市场是最好的信号（22.7 万场）

| 市场最高隐含概率档 | 实际命中率 | 偏差 |
|:--|:--|:--|
| 35–45% | 40.5% | +0.3pp |
| 45–55% | 50.7% | +1.1pp |
| 55–70% | 63.0% | +2.0pp |
| 70%+ | 80.6% | **+4.4pp（系统性热门低估）** |

**结论**：市场（欧赔去水）校准度在 ±5pp 内，且系统性低估热门 → 设为现场引擎**最大单源**（权重 0.30）。

---

## 2. 弱共识场：平局必须并列（22.7 万场）

用 **skew**（市场最高 / 次高隐含概率之比）衡量市场共识强度：

| skew | 市场首选命中率 | 处理 |
|:--|:--|:--|
| <110% | 36.4% | 🔴 平局必须并列（≈随机） |
| 110–130% | 38.6% | 🔴 平局必须并列 |
| 130–150% | 43.0% | 🔴 平局必须并列 |
| 150–200% | 48.8% | 可单押（谨慎） |
| ≥200% | **64.6%** | 可单押 |

**结论**：skew <150% 时单押市场首选 ≈ 赌博；平局并列可显著提升覆盖。

## 3. 比分锚的可信度分级（案例库实证）

| 场景 | 锚命中率 |
|:--|:--|
| 实际总进球 ≤3 球 | **36.4%** |
| 实际总进球 ≥4 球 | **2.9%** |
| 实际总进球 ≥5 球 | **0%** |
| 「≤3球 且 净胜≤1」 | **40.0%** |
| 「≥4球 且 净胜≥2」 | 4.9% |

**结论**：**大球场/深盘大胜场 → 禁止把"主锚/次锚"当高置信输出**，改输出宽候选池 + "比分不可预测"标注（方向仍可用）。

---

## 4. 大小球：信号强度三档（148,397 场时间分割）

| 档 | 阈值（over 概率） | 实测下限 |
|:--|:--|:--|
| 🔴 强 | ≥58% / ≤42% | 大球 65.0% / 小球 62.6% |
| 🟡 中 | 55–58% / 42–45% | 57.0% / 58.0% |
| ⚪ 弱 | 53–55% / 45–47% | 54.8% / 54.1%（≈随机·仅参考） |
| ⚫ 中性 | 47–53% | 不判方向 |

**基线**（53% 阈值全档）：59.54%。
**已否决（回测零/负增益）**：赔率偏差微校准、大/小球不对称阈值、ELO 叠加。

---

## 5. 防过拟合门禁（四道）

1. **回测门禁**：新特征/新权重必须时间分割回测 + 配对显著性 p<0.05
2. **样本门禁**：n<50 → 权重 0；50–200 → 0.05；≥200 → 0.10（封顶）
3. **回滚门禁**：滚动 20 场偏差 >10pp → 自动降级为"仅记录"
4. **输出裁剪**：超范围值丢弃 / 缺失不计入 / 无数据三态标注

> **实例**：在线机器学习层（L1）经 30000 场时间分割实测**无增益**（-14.2pp）→ 显式降级 `degraded`，权重 0，仅记录不参与判定。

## 6. 置信度口径（严谨优先）

| 档 | 定义（strict 口径·仅主方向） |
|:--|:--|
| HIGH | ≥70% |
| MID | 55–70% |
| MID-LOW | 45–55% |
| LOW | <45% |

**口径纪律**：统计一律用 **strict**（仅主方向命中）；含并列/次方向的宽口径会虚高，仅作参考。

| 方案 | 回测结论 |
