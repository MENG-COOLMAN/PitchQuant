# 数据与 API 清单 · Required Data & API Checklist

> 🔴 **本节回答一个问题：跑起来到底需要什么？哪些是你必须自备的？**
> This page answers one question: what do you actually need to bring yourself?

---

## ⚡ TL;DR（最少配置）

| 级别 | 你需要准备 | 说明 |
|:--|:--|:--|
| ✅ **必须** | **竞彩赔率 txt**（自己记录） | 唯一硬性输入；没有它什么都跑不了 |
| 🟡 **强烈建议** | **欧盘赔率**（任一欧赔源） | 决定"现场比分引擎"是否启用（权重最大的一源） |
| 🟡 **建议** | 亚盘盘口/水位 + 大小球盘 | 提升方向与量级判定精度 |
| ⭕ **可选** | ELO / xG / 官方概率 / 伤停 | 交叉验证用；没有则对应模块显式标"无数据" |

> **没有 API key 也能跑。** 但要知道代价：跳过的是**交叉验证层**，不是核心计算层。

## 一、你必须自备的数据 · Data You Must Provide

| # | 数据 | 必须度 | 用途（哪个参数/模块） | 获取方式 | 格式要点 |
|:--|:--|:--|:--|:--|:--|
| 1 | **竞彩赔率变动序列** | ✅ **必须** | 输入文件（`calc_all` 第一个参数） | 🔴 **中国体育彩票官网**（<https://www.lottery.gov.cn/jc/index.html>）的**每日公开数据** —— 赛前多次抄录同场赛事即形成变动序列 | `【节名】` + 逗号赔率 + `→` 分隔时点 |
| 2 | **欧盘胜平负** | 🟡 强烈建议 | `--eu 主,平,客` → 去水基准 + live 引擎最大源（0.30） | 任一欧赔源（含 Odds-API，见下） | 三位小数，如 `2.836,3.415,2.704` |
| 3 | **亚盘让球 + 水位** | 🟡 建议 | `--handi`（负=主让）+ `--home_water` | 亚盘数据源 | 让球如 `-1`、`0.25`；水位如 `1.85` |
| 4 | **大小 2.5 球盘** | 🟡 建议 | `--o25 / --u25` → 量级与比分约束 | 大小球源 | 如 `1.827 / 2.137` |
| 5 | **历史比赛数据**（回测） | ⭕ 可选 | `scripts/backtest/*` 回测脚本 | 自备 CSV/SQL（公开数据源如 football-data.co.uk 提供免费历史 CSV） | 需含比分/赔率字段 |
| 6 | **xG 数据** | ⭕ 可选 | 攻防验证（SK-xg-depth） | Understat 等免费源（自行抓取） | 只允许用**赛前可得的历史滚动均值**（防数据泄露） |
| 7 | **ELO 值** | ⭕ 可选 | `--elo` → ELO 一致性校验 | clubelo.com 等免费源 | 传**两队差值** |

**最少可用组合**：只有第 1 项（竞彩 txt）→ 仍能产出：去水概率 / 方向差距 / skew / 档位查表 / 大小球档 / 比分查表。

## 二、你需要申请的 API · APIs You May Need

### 2.1 Odds-API（欧盘全市场·主数据源）— 🟡 推荐

| 项 | 内容 |
|:--|:--|
| **用途** | 欧盘 ML / 亚盘 / 大小球 / 比分盘(CS) / BTTS / 半全场 全市场快照 |
| **在模型里** | `--eu` 参数的来源；`live` 引擎的 market 源（权重 0.30，最大单源） |
| **免费额度** | 有免费 tier（通常限 1xbet 全市场 + Bet365 部分市场），**够个人研究用** |
| **申请** | 官网注册 → 获取 API Key |
| **环境变量** | `ODDS_API_KEY=...` |
| **调用方式** | 本仓库脚本读环境变量；示例：`?sport=football&league=england-premier-league` |
| **支持联赛** | 五大联赛有标准 slug；部分杯赛/小联赛可能未收录（脚本会标注"未收录"） |

### 2.2 api-football（官方概率 + 13 家赔率 + 伤停）— 🟡 推荐

| 项 | 内容 |
|:--|:--|
| **用途** | ① 官方模型概率（交叉验证）② 13 家博彩赔率（跨机构分歧）③ **伤停名单**（位置级影响分） |
| **在模型里** | 交叉验证层 + `--inj_h/--inj_a` 影响分的原始数据 |
| **免费额度** | 免费 tier 约 100 次/天（三端点链调用一次约 3–4 次） |
| **申请** | 官网注册（RapidAPI 亦提供） |
| **环境变量** | `API_FOOTBALL_KEY=...` |
| **🔴 调用要点** | 定位比赛只用 **`fixtures?date=YYYY-MM-DD`**（UTC 日）；**不要**同时带 league+season 参数（会报错） |

### 2.3 免费但无需 key 的源（需自行抓取）

| 源 | 用途 | 方式 | 注意 |
|:--|:--|:--|:--|
| **clubelo.com** | 实时 ELO | 页面/API 抓取（本仓库含抓取脚本） | 免费、每日更新；需别名映射匹配队名 |
| **understat.com** | xG | JSON 端点抓取 | 仅五大联赛；**只用历史滚动均值**（防泄露） |
| **football-data.co.uk** | 历史赛果+赔率 CSV | 直接下载 | 适合自建回测数据集 |
| **竞彩官方/各彩票网站** | 竞彩赔率 | 手工记录 | 变动序列需多次抄录 |

### 2.4 可选：本地代理

部分源（新闻抓取、部分欧盘接口）在受限网络下需要代理：
```bash
# .env
HTTPS_PROXY=http://127.0.0.1:7897     # 换成你自己的端口
HTTP_PROXY=http://127.0.0.1:7897
```

## 三、不用任何 API 也能跑（降级模式说明）

当某个源不可用时，模型**不会猜**，而是按"三态标注"继续：

```
触发(数值)   /   不触发(原因)   /   无数据(原因)
```

| 没有的东西 | 后果 | 补救 |
|:--|:--|:--|
| 欧盘 | live 引擎不触发（只剩竞彩侧） | 手工从任一欧赔源抄 `--eu` |
| ELO | ELO 一致性校验标"无数据" | 跳过，或手查 clubelo |
| 伤停 | 影响分为空（不参与 λ 调整） | 自己评估"位置 × 重要性"给个分数 |
| xG | xG 深度模块标"无数据" | 跳过 |
| 历史数据 | 回测脚本不可用 | 核心预测不受影响 |

## 五、配置检查清单 · Setup Checklist

```
□ ① Python 3.10+ 已安装
□ ② git clone 完成
□ ③ （可选）pip install -r requirements.txt
□ ④ （可选）cp .env.example .env 并填入 ODDS_API_KEY
□ ⑤ （可选）填入 API_FOOTBALL_KEY
□ ⑥ （可选）设置代理（受限网络）
□ ⑦ 准备一个竞彩赔率 txt（含 ≥2 个时点）
□ ⑧ 跑通：python scripts/tmp/calc_all.py <txt> <联赛> [参数…]
□ ⑨ 环境自检：python scripts/tmp/check_sync.py
□ ⑩ 看过 examples/ 里的完整案例
```

**完成 ①⑦⑧ 即"最小可用"；补齐 ④⑤ 得到完整交叉验证能力。**
