# 数据与 API 清单 · Required Data & API Checklist

> 本文件说明：**你必须自备什么**、需要哪些 API、免费额度、以及**缺少某个源时模型会怎么降级**（不会猜，只会三态标注）。

---

## ⚡ TL;DR（最少配置）

| 级别 | 你需要准备 | 说明 |
|:--|:--|:--|
| ✅ **必须** | **竞彩赔率 txt**（自己记录） | 唯一硬性输入；没有它什么都跑不了 |
| 🟡 **强烈建议** | **欧盘赔率**（任一欧赔源） | 决定"现场比分引擎"是否启用（权重最大的一源） |
| 🟡 **建议** | 亚盘盘口/水位 + 大小球全档 | 提升方向、量级与让球穿透判定精度 |
| ⭕ **可选** | ELO / xG / 结构化伤停 / 波胆全档 | 交叉验证用；没有则对应模块显式标"无数据" |

> **没有 API key 也能跑。** 但要知道代价：跳过的是**交叉验证层**，不是核心计算层。

> 🔴 **2026-10 变更**：`api-football` 已**停用并从数据链剔除**。
> 替代映射：赔率 → **the-odds-api** ｜ 伤停 → **Bzzoiro** ｜ 赛事定位 → **Odds-API**
> ｜ 官方概率 / 首发阵容 → ⚪ **无替代**（三态标注，不参与判定）。

## 一、你必须自备的数据 · Data You Must Provide

| # | 数据 | 必须度 | 用途（哪个参数/模块） | 获取方式 | 格式要点 |
|:--|:--|:--|:--|:--|:--|
| 1 | **竞彩赔率变动序列** | ✅ **必须** | 输入文件（`calc_all` 第一个参数） | 🔴 **中国体育彩票官网**（<https://www.lottery.gov.cn/jc/index.html>）的**每日公开数据** —— 赛前多次抄录同场赛事即形成变动序列 | `【节名】` + 逗号赔率 + `→` 分隔时点 |
| 2 | **欧盘胜平负** | 🟡 强烈建议 | `--eu 主,平,客` → 去水基准 + live 引擎最大源（0.30） | 任一欧赔源（含 Odds-API，见下） | 三位小数，如 `2.836,3.415,2.704` |
| 3 | **亚盘让球 + 水位** | 🟡 建议 | `--handi`（负=主让）+ `--home_water` | 亚盘数据源 | 🔴 必须传**欧盘均衡线**（不是竞彩固定 ±1） |
| 4 | **大小 2.5 球盘** | 🟡 建议 | `--o25 / --u25` → 量级与比分约束 | 大小球源（全档更好，可算均衡线） | 如 `1.827 / 2.137` |
| 5 | **历史比赛数据**（回测） | ⭕ 可选 | `scripts/backtest/*` 回测脚本 | 自备 CSV/SQL（football-data.co.uk 提供免费历史 CSV） | 需含比分/赔率字段 |
| 6 | **xG 数据** | ⭕ 可选 | 攻防验证（SK-xg-depth） | Understat 等免费源（自行抓取） | 只允许用**赛前可得的历史滚动均值**（防数据泄露） |
| 7 | **ELO 值** | ⭕ 可选 | `--elo` → ELO 一致性校验 | clubelo.com 等免费源 | 传**两队差值** |

**最少可用组合**：只有第 1 项（竞彩 txt）→ 仍能产出：去水概率 / 方向差距 / skew / 档位查表 / 大小球档 / 比分查表。

## 二、你需要申请的 API · APIs You May Need

### 2.1 Odds-API（欧盘全市场 · 主数据源）— 🟡 推荐

| 项 | 内容 |
|:--|:--|
| **用途** | 欧盘 ML / 亚盘 / 大小球 / 比分盘(CS) / BTTS / 半全场 全市场快照；**赛事定位（eventId）** |
| **在模型里** | `--eu` 参数的来源；`live` 引擎的 market 源（权重最大）；P10 三源矩阵的原料 |
| **免费额度** | 有免费 tier（通常限 1xbet 全市场 + Bet365 部分市场），**够个人研究用** |
| **申请** | 官网注册 → 获取 API Key |
| **环境变量** | `ODDS_API_KEY=...` |
| **调用方式** | `?sport=football&league=england-premier-league` → `get_odds(eventId)` |
| **🔴 支持联赛** | 五大联赛有标准 slug；部分杯赛/小联赛可能未收录（脚本会标注"未收录"，**不是源不可用**） |
| **🔴 通道实测** | **代理优先**（约 1.2s）→ 直连回退（SSL 握手常 24s+）：默认配置下差约 400 倍 |

### 2.2 the-odds-api（21–40 家机构 · 跨市场分歧）— 🟡 推荐

| 项 | 内容 |
|:--|:--|
| **用途** | ① **跨机构分歧**（`spread = (Max−Median)/Median` · 只调置信度）② 亚盘多档 ③ BTTS ④ 多元合并去水 |
| **在模型里** | P0-1 跨机构分歧层 · 机构共识层 · 亚盘多档交叉验证 |
| **免费额度** | 500 请求/月（`current` 可用；`history` / `range` 需付费） |
| **申请** | 官网注册 → API Key |
| **环境变量** | `THE_ODDS_API_KEY=...`（可用 `THE_ODDS_API_POOL` 配 key 池，用尽自动轮转） |
| **🔴 调用要点** | **必须显式指定联赛**（默认 sport 是欧国联，不指定会误判"该源不覆盖此联赛"） |
| **🔴 报错语义** | `HISTORICAL_UNAVAILABLE_ON_FREE_USAGE_PLAN` = **功能需付费**（换任何免费 key 都无效）· `INVALID_KEY` = key 错误（切下一个 key） |

### 2.3 Bzzoiro（结构化伤停 / 名单 / 近况）— 🟡 推荐

| 项 | 内容 |
|:--|:--|
| **用途** | ① **结构化伤停**（位置 `G/D/M/F` + `injured/doubtful/suspended` + 回归日）② 名单 ③ **Form5**（近 5 场场均积分） |
| **在模型里** | 铁则32 位置级影响分（`--inj_h/--inj_a`）的**唯一结构化来源**；PreStep F1 信号 |
| **申请** | 官网注册 → API Key（足球免费，约 10 req/s） |
| **环境变量** | `BZZOIRO_KEY=...` |
| **🔴 调用要点** | 已知 event id 时用 `--event`（零扫描）；否则 `--teams "Home,Away"` 走索引（带 6h 缓存） |
| **🔴 定位失败** | 标「伤停维度不可用（未定位）」+ 原因，**禁用新闻标题推测**（已废止路径） |

### 2.4 智谱 GLM（可选 · 截图 → 赔率文本）

| 项 | 内容 |
|:--|:--|
| **用途** | `pipeline.py <图片>` 时自动 OCR（GLM-OCR 版面识别 / GLM-4.6V 赛事页分流） |
| **在模型里** | 仅输入层，不参与任何判定 |
| **环境变量** | `ZHIPU_API_KEY=...` |
| **不需要时** | 直接手敲竞彩 txt 即可，功能完全等价 |

### 2.5 免费但无需 key 的源（需自行抓取）

| 源 | 用途 | 方式 | 注意 |
|:--|:--|:--|:--|
| **clubelo.com** | 实时 ELO | 页面/API 抓取（本仓库含抓取脚本） | 免费、每日更新；需别名映射匹配队名 |
| **understat.com** | xG | JSON 端点抓取 | 仅五大联赛；**只用历史滚动均值**（防泄露） |
| **football-data.co.uk** | 历史赛果+赔率 CSV | 直接下载 | 适合自建回测数据集 |
| **竞彩官方/各彩票网站** | 竞彩赔率 | 手工记录 | 变动序列需多次抄录 |

### 2.6 可选：本地代理

部分源在受限网络下需要代理：
```bash
# .env
HTTPS_PROXY=http://127.0.0.1:7897     # 换成你自己的端口
HTTP_PROXY=http://127.0.0.1:7897
```
> 🔴 实测：`open.bigmodel.cn` 直连 TCP/TLS 握手约 24s，走代理 0.06s → 脚本默认 **代理优先、直连快速失败回退**。

## 三、不用任何 API 也能跑（降级模式说明）

当某个源不可用时，模型**不会猜**，而是按"三态标注"继续：

```
触发(数值)   /   不触发(原因)   /   无数据(原因)
```

| 没有的东西 | 后果 | 补救 |
|:--|:--|:--|
| 欧盘 | live 引擎不触发（只剩竞彩侧）；跨市场分歧失效 | 手工从任一欧赔源抄 `--eu` |
| ELO | ELO 一致性校验标"无数据" | 跳过，或手查 clubelo |
| 结构化伤停 | 影响分为空（不参与 λ 调整） | 自行评估"位置 × 重要性"给个分数并标注来源 |
| xG | xG 深度模块标"无数据" | 跳过 |
| 波胆全档 | P10 三源矩阵不生成 → 回退 R10/泊松链路 | 用 Odds-API 拉全市场 |
| 历史数据 | 回测脚本不可用 | 核心预测不受影响 |

> 🔴 **「源 missing」≠「源不可用」**：常见真因是**队名解析失败**（中文简称 → 英文事件名）或**缺参数**（联赛 slug / 联赛名）。
> 本项目内置 `cn2en_online.py` 三级回退（本地三表 → 中文维基 langlinks → 搜索兜底，带相关度校验）。

## 五、配置检查清单 · Setup Checklist

```
□ ① Python 3.10+ 已安装
□ ② git clone 完成
□ ③ （可选）pip install -r requirements.txt
□ ④ （可选）cp .env.example .env 并填入 ODDS_API_KEY
□ ⑤ （可选）填入 THE_ODDS_API_KEY（跨机构分歧）/ BZZOIRO_KEY（结构化伤停）
□ ⑥ （可选）设置代理（受限网络 · 注意代理优先比直连快得多）
□ ⑦ 准备一个竞彩赔率 txt（含 ≥2 个时点）
□ ⑧ 跑通：python scripts/tmp/calc_all.py <txt> <联赛> [参数…]
□ ⑨ 环境自检：python scripts/tmp/check_sync.py
□ ⑩ 看过 examples/ 里的完整案例
```

**完成 ①⑦⑧ 即"最小可用"；补齐 ④⑤ 得到完整交叉验证能力。**

🔴 **两个会让全部结论静默失真的参数陷阱**：
- `--eu` 必须是**真实欧盘**（禁用竞彩末盘冒充 → 否则跨市场分歧恒为 0 = 假一致）
- `--handi` 必须是**欧盘均衡线**（禁用竞彩固定 ±1 → 否则净胜档 / 让球水位 / 受让禁锚全部失真）
